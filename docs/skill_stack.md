# 技術スタック表示機能 仕様書

---

## 1. 概要

本機能は、ユーザの技術スタックをレベル別に整理して表示するものである。
閲覧者（企業・エンジニア）がスキルレベルを直感的に理解できることを目的とする。

---

## 2. 表示方針

技術スタックは以下の4段階で分類して表示する。

1. 主に使用（自力で実装可能）
2. 基礎理解あり
3. 学習中
4. 使用経験あり（AI補助・コード理解可）

---

## 3. データ構造

### 3.1 技術スタックデータ（skills）

```json id="skill01"
{
  "_id": "string",
  "name": "string",
  "category": "string",
  "level": "string",
  "description": "string"
}
```

---

### 3.2 levelの定義

| 値           | 説明      |
| ----------- | ------- |
| advanced    | 自力で実装可能 |
| basic       | 基礎理解あり  |
| learning    | 学習中     |
| experienced | 使用経験あり  |

---

### 3.3 categoryの定義

| 値        | 説明      |
| -------- | ------- |
| language | 言語      |
| frontend | フロントエンド |
| backend  | バックエンド  |
| database | データベース  |

---

## 4. 表示仕様

### 4.1 レイアウト

* レベルごとにセクションを分けて表示
* 各セクション内に技術タグを配置

---

### 4.2 表示例

#### ● 主に使用（自力で実装可能）

* C++

---

#### ● 基礎理解あり

* HTML / CSS

---

#### ● 学習中

* JavaScript
* Python
* Node.js / Express

---

#### ● 使用経験あり（AI補助・コード理解可）

**フロントエンド**

* React / Next.js
* TypeScript
* Flutter（Dart）
* Tailwind CSS
* WebGL

**バックエンド**

* Spring Boot
* Go
* Java

**データベース / BaaS**

* PostgreSQL
* MongoDB
* Firebase
* Supabase

---

## 5. UI仕様

### 5.1 技術タグ

* カードまたはバッジ形式
* ホバー時に説明表示（tooltip）

---

### 5.2 色分け（任意）

| レベル         | 色   |
| ----------- | --- |
| advanced    | 強調色 |
| basic       | 標準色 |
| learning    | 注意色 |
| experienced | サブ色 |

---

### 5.3 レスポンシブ対応

* スマホでは縦並び
* PCではグリッド表示

---

## 6. インタラクション

### 6.1 フィルタ機能（任意）

* カテゴリ別に絞り込み可能

---

### 6.2 ソート機能（任意）

* レベル順に表示

---

## 7. 管理機能

### 7.1 技術スタック登録

* 技術名
* カテゴリ
* レベル
* 説明

---

### 7.2 編集・削除

* 既存データの更新・削除が可能

---

## 8. 非機能要件

### 8.1 可読性

* 一目でレベルが理解できること

### 8.2 信頼性

* 誇張した表現を避ける

---

## 9. 拡張案

* 制作物との紐付け表示
* 使用頻度の可視化
* 習得率との連動

---
